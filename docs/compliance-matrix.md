## 1. Compliance Status Taxonomy

Every statutory requirement is classified under one of the following authoritative status states:

1. **`IMPLEMENTED & INTERNALLY TESTED`**: Module logic, database models, and automated test cases exist in the repository, and tests pass in the local test environment.
2. **`UAT-VERIFIED (MOCK DRIVER)`**: Automated synthetic journeys and simulated flows pass using labeled mock drivers (`INTEGRATION_DRIVER=MOCK`), proving contract compliance without external dependencies.
3. **`AWAITING EXTERNAL ACCESS / PRODUCTION CREDENTIALS`**: Implementation is complete, but end-to-end production verification is pending the issuance of government OAuth2 client credentials, mTLS certificates, or sandbox credentials by the respective authority.
4. **`AWAITING REGULATOR DECISION / FORMAL AUDIT`**: Formal documentation is prepared and ready for submission; official assessment, on-site audit, or formal gazettement by the regulator is pending.
5. **`AWAITING CLINICAL / LEGAL SIGN-OFF`**: Technical capability is functional, but pending formal review and wet/digital signature from Kenyan legal counsel or medical advisory boards.
